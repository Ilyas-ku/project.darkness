# Сосновый лагерь — Prototype 0.3 «Sound & Stealth»

2D top-down тактический хоррор, Godot **4.7.2**, GDScript, без внешних пакетов и сетевых ресурсов.
Один выживший (игрок) против ИИ-маньяка на карте ForestTest_01 (30 × 24 gu, 1 gu = 32 px).

Что нового в 0.3:
- шаги маньяка слышны **из закрытого шкафа** и из-за стены: стены и двери приглушают, но не глушат;
- шаги звучат **позиционно (стерео)**, на карте появляется **размытая метка** приблизительной области;
- два источника шагов дают **два независимых ритма**;
- **кусты** реально прячут (зависит от движения) и **шуршат**, когда через них идут;
- **двери** открываются нажатием за 0,2 с, не останавливая игрока;
- у событий **отдельные звуки**: дверь, шкаф, окно, бросок, удар, ранение, выход.

Всё из 0.2 сохранено: обыск дома и шкафов, честный LastSeen, ранение → повал → добивание, окно, выход по удержанию E 5 с, многоразовые камни, память карты, графика.

## Запуск
- **Godot:** 4.7.2-stable. Главная сцена: `res://scenes/main/forest_test_01.tscn`.
- **Редактор:** Project Manager → Import → `project.godot` → F5.
- **Консоль:**
  ```
  godot --path .                                   # игра
  godot --path . -- --preset=TEST_STEPS_CLOSET     # debug-пресет (список ниже), seed 42
  godot --path . -- --seed=42 --skip-prep --debug
  ```
- **Тесты и проверки (headless):**
  ```
  godot --headless --path . --import
  godot --headless --path . --fixed-fps 60 -s res://tests/run_tests.gd        # 60 тестов, код 0 = всё прошло
  godot --headless --path . --fixed-fps 60 -s res://tools/chase_trials.gd     # 10 погонь (T35)
  godot --headless --path . --fixed-fps 60 -s res://tools/soak_test.gd        # 10 мин ботом
  ```
- **Запись видео со звуком (доказательство звука):**
  ```
  godot --path . --write-movie out.avi --fixed-fps 30 --quit-after 420 -- --preset=TEST_STEPS_CLOSET
  python3 tools/analyze_audio.py out.avi 0.5      # громкость, стерео-баланс и всплески по времени
  ```

### Как проверить шаги из шкафа и кусты (≈ 5 минут, в наушниках)
1. F2 → `TEST_STEPS_CLOSET`: вы в закрытом шкафу. Маньяк проходит по спальне: слышны приглушённые шаги с нужной стороны, поверх изученной карты пульсирует пятно. Маньяк стоит у шкафа 2 с — новых шагов нет, пятно гаснет.
2. F2 → `TEST_STEPS_WALL`: маньяк ходит за северной стеной спальни. Шаги слышны глухо, его самого не видно.
3. F2 → `TEST_STEPS_TWO_RUNNERS`: смотрите на юг. За спиной один бегун бежит, другой идёт — два наложенных ритма; через 8 с остаётся один.
4. F2 → `TEST_BUSH_WALK_RUN`: маньяк смотрит на куст. Пройдите его с Ctrl, шагом и с Shift: шорох всё громче, листва качается только при движении.
5. F2 → `TEST_BUSH_STATIC`: стойте в кусте неподвижно — маньяк проходит рядом и не видит.
6. F2 → `TEST_DOOR_SPRINT`: бегите к двери и нажмите E на бегу — открывается без остановки.
7. F3 в любой момент: цепочка «событие → слышимость → голос → метка», реальная точка события (только в debug), сектор и состояние маньяка.

## Как устроен звук
```
Actor moves -> FootstepEmitter (шаг на каждую реально пройденную длину шага; материал wood/dirt/grass; своя фаза)
            -> SoundEventBus -> Acoustics (дистанция, стены и двери ×0.6, шкаф слушателя ×0.8: ослабляет, не глушит)
            -> HearingSensor -> PerceivedSound {категория, приблизительная область 1.5–3 gu, громкость, приглушённость, поверхность}
                 ├─ AudioDirector: позиционный голос (стерео) в области, громкость по акустике, low-pass-шина при приглушении
                 ├─ SoundMarkers: размытое пятно на карте (то же событие → нет звука = нет метки)
                 └─ AIMemory/KillerBrain: проверка области, а не точки
```
Наблюдение не содержит id источника, роли, точной позиции и числа источников. Шины: Master, Ambient, Footsteps(+Muffled), SFX(+Muffled), UI; громкость и выключение меток — в паузе (`user://settings.cfg`).

Кусты: дальность обнаружения цели внутри куста × 0,25 / 0,40 / 0,60 / 0,85 (стоит / крадётся / идёт / бежит) плюс 0,5 с на распознавание; одинаково для обеих сторон. Шорох — от движущегося персонажа: 2 / 3,5 / 5 gu, интервал 0,5 / 0,36 / 0,28 с, стоя — ничего.

Все числа — в `scripts/config/game_params.gd` (Приложение A ТЗ).

## Ограничения (честно)
- **Звук ушами не слушался исполнителем** (нет аудиовыхода). Есть записи из игры и их программный анализ; субъективную проверку в наушниках (T19) нужно сделать вам.
- **Ручной плейтест с клавиатурой и мышью не проводился**; ввод в тестах программный.
- **FPS на видеокарте не измерялся.** На программном рендере llvmpipe ~17 FPS при 1080p — не показатель.
- Стереоразнос в Godot 2D слабый по умолчанию. Он усилен (смещение источника ×3 по горизонтали, сила панорамы 2), но в записях баланс шагов умеренный (±0,2 по окнам 0,5 с).
- Бутылка за стеной звучит тихо — так задумано (low-pass + ослабление стеной).
- Звуковые пятна рисуются поверх тумана как размытые круги. Геометрию они не раскрывают, но видны и над неизученной (чёрной) частью экрана.
- Окно, закрытое ставнями (1,4 с), не реализовано: окно в доме открытое (0,9 с).
- Ветка `claude/youthful-carson-o6jall` вместо `feature/prototype-0.3-sound-stealth`: окружение разрешает пушить только в неё. PR не открыт: в репозитории нет базовой ветки (`main`).
- При выходе из тестового раннера Godot печатает предупреждения об утечках тестовых узлов; на игру не влияет.
