# AUDIT 0.3 — этап 0 обновления до Prototype 0.3 «Sound & Stealth»

Дата: 24.10.2026. Исходное состояние: Prototype 0.2, коммит `e6209f0`, ветка `claude/youthful-carson-o6jall`,
`origin = https://github.com/Ilyas-ku/project.darkness`. Рабочее дерево чистое. Godot 4.7.2-stable.

## Разведка
- Корень: `project.godot`; главная сцена `res://scenes/main/forest_test_01.tscn`. Плагинов и экспортных пресетов нет.
- Ветки: в репозитории одна ветка `claude/youthful-carson-o6jall`, ветки `main` нет. Окружение разрешает пушить только в эту ветку, поэтому
  `feature/prototype-0.3-sound-stealth` не создаётся; работа продолжается обычными коммитами (без force-push). PR открыть некуда: нет базовой ветки.
- Стартовая работоспособность 0.2 подтверждена: импорт без ошибок, 48/48 тестов, игра запускается.
- Godot Movie Maker (`--write-movie`) в этом окружении пишет видео MJPEG + стерео PCM 48 кГц — это позволяет приложить **реальную запись игрового звука** и анализировать её программно (громкость, стерео-баланс). Прослушать звук ушами исполнитель не может.
